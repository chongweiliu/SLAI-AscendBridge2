# 本机部署

仅支持 `single_node`。多机必须改选 SSH 或调度平台。

## 自动默认

- 自动检查当前 Python 环境和本机镜像，只在没有兼容环境或存在多个冲突候选时询问。
- 自动读取可见 NPU 和模型配置，规划运行 NPU、TP/DP/EP。
- 服务端口默认 8000，占用时自动选择空闲端口。
- 仅应用用户在提示词中明确要求的额外 vLLM 参数。

## 预检与生命周期

检查 `config.json` 和权重分片、`npu-smi info`、torch-npu/CANN/vLLM 版本、端口和容器设备透传。若当前主机本身位于容器中，先运行最小 torch-npu/Triton 探针；内层容器启动不代表 NPU 可用。

使用受控前台进程或服务管理器，记录 PID。轮询 API 时同步检查进程；提前退出立即保存日志。失败时只终止本次创建的进程。
